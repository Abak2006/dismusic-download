# Dismusic

Downloads and website for **Dismusic**, a Windows 10/11 tray app for per-app audio output, playing one source on several devices in sync, audio that follows the screen a window is on, and per-app boost and equalizer without a driver.

- Website: https://abak2006.github.io/dismusic-download/
- Download: see [Releases](https://github.com/Abak2006/dismusic-download/releases/latest)

This repository holds only the website and release files.
